# JavaScript CRUD Operations with MockAPI

A JavaScript project demonstrating full CRUD operations using the MockAPI REST API.

## 🚀 Features

- Fetch all users
- Fetch a user by ID
- Create a new user
- Update existing user data
- Delete a user
- Uses separate functions for each API operation
- Uses `async/await` for handling API requests
- Logs API responses using `console.log()`

## 🛠️ Technologies Used

- JavaScript
- Fetch API
- REST API
- MockAPI

## 🔄 CRUD Operations

| Operation | Method | Endpoint |
|---|---|---|
| Get all users | GET | `/users` |
| Get user by ID | GET | `/users/:id` |
| Create user | POST | `/users` |
| Update user | PUT | `/users/:id` |
| Delete user | DELETE | `/users/:id` |
